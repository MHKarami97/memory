# خاطره‌نامه (KhaterehNameh)

وب‌اپلیکیشن PWA کاملاً سمت کاربر، امن و بدون بک‌اند برای ثبت، مرور و مدیریت خاطرات شخصی با زبان فارسی و تقویم شمسی.

---

## 🌟 ویژگی‌های کلیدی

- **کاملاً آفلاین و بدون سرور (Zero Backend)**: تمام داده‌ها، متون، عکس‌ها و فایل‌های صوتی فقط و فقط در مرورگر و دیتابیس محلی دستگاه شما ذخیره می‌شوند. هیچ داده‌ای به هیچ سرور خارجی ارسال نمی‌گردد.
- **طراحی ریسپانسیو اختصاصی برای هر دستگاه**:
  - **موبایل**: منوی لمسی پایین (Bottom Navigation)، دکمه بزرگ شناور «+»، فرم‌های متمرکز و بهینه برای کار با یک دست و پشتیبانی از Safe Area.
  - **تبلت**: چیدمان دو ستونه (Master-Detail) با مرور سریع لیست خاطرات و مطالعه همزمان.
  - **دسکتاپ**: سایدبار کامل، چیدمان سه ستونه (Sidebar + Timeline + Detail Panel)، حالت اسپلیت، میانبرهای کیبورد (`Ctrl+N`، `Ctrl+S`، `Ctrl+F`، `Escape`).
- **ثبت چندرسانه‌ای غنی**:
  - فشرده‌سازی خودکار و بهینه‌سازی تصاویر قبل از ذخیره با ایجاد بندانگشتی (Thumbnail) سبک و نمایش مقایسه حجم قبل و بعد.
  - ویرایشگر حرفه‌ای Markdown با دکمه‌های پرکاربرد (Bold, Italic, Headings, Lists, Quotes, Code, Divider) با حالت پیش‌نمایش زنده و امن‌شده در برابر XSS با DOMPurify.
  - ضبط صوت با میکروفون و نمایش مدت زمان.
  - تبدیل صوت به متن (Speech-to-Text) در دو حالت: سیستمی مرورگر (Web Speech API با هشدار امنیتی) و مدل‌های محلی خانواده ویسپر (Whisper) کاملاً آفلاین روی پردازنده دستگاه.
  - ضمیمه کردن انواع فایل‌های پیوست (PDF، صوت، اسناد).
  - ذخیره‌سازی خودکار پیش‌نویس (Draft Auto-Save) برای جلوگیری از پاک شدن ناگهانی متن.
- **گاه‌شمار و خط زمانی شمسی**:
  - تبدیل دقیق تاریخ‌ها با کتابخانه استاندارد `jalaali-js`.
  - تقویم ماهانه شمسی با مشخص کردن روزهای دارای خاطره و امکان انتخاب روزها.
  - بخش «چند سال پیش در چنین روزی» (Flashback) برای مرور خاطرات گذشته.
  - دسته‌بندی‌های «امروز»، «این ماه»، «امسال» و فیلترهای برچسب و اشخاص.
- **امنیت پیشرفته و قفل برنامه**:
  - قفل برنامه با رمز عبور عددی هش‌شده با الگوریتم امن PBKDF2 و Salt تصادفی (بدون ذخیره رمز خام).
  - پشتیبانی از ورود بیومتریک (WebAuthn) با اثر انگشت، Face ID یا قفل صفحه سیستم‌عامل.
  - وقفه زمانی حفاظتی (Cool-down) در صورت تکرار رمز اشتباه.
  - امکان قفل کردن اختصاصی یک خاطره خاص.
- **پشتیبان‌گیری رمزگذاری‌شده و استاندارد**:
  - خروجی فایل پشتیبان رمزگذاری‌شده با کلید ۲۵۶ بیتی AES-GCM مشتق‌شده با PBKDF2 و ۱۰۰٬۰۰۰ دور تکرار.
  - پیش‌نمایش تعداد خاطرات و تاریخ تهیه قبل از بازگردانی.
  - انتخاب میان ادغام (Merge) یا جایگزینی کامل (Replace).
  - امکان خروجی متنی JSON غیررمزگذاری‌شده همراه با هشدار امنیتی.
- **خروجی PDF فارسی و اشتراک‌گذاری**:
  - ساخت ۱۰۰٪ کلاینتی فایل PDF با قلم وزیرمتن (Vazirmatn)، تاریخ شمسی، چیدمان RTL و انتخاب گنجاندن عکس‌ها.
  - اشتراک مستقیم با Web Share API در گوشی و تبلت با امکان دانلود مستقیم.
- **یادآور هوشمند روزانه**:
  - ارسال اعلان روزانه با Web Notification API در ساعت دلخواه.
  - بررسی خودکار: در صورتی که خاطره آن روز قبلاً نوشته شده باشد، اعلانی ارسال نمی‌شود تا کاربر اذیت نشود.
- **PWA پیشرفته**:
  - نصب آسان به عنوان اپلیکیشن مستقل در اندروید، iOS، ویندوز و مک.
  - کش هوشمند App Shell و فونت‌ها در Service Worker.
  - سیستم هشدار بروزرسانی خودکار بدون سفیدی صفحه یا اختلال در کش.

## 🛠 معماری نرم‌افزار

پروژه به صورت کاملاً ماژولار و بر پایه الگوهای مهندسی نرم‌افزار پیاده‌سازی شده است:

- **Repository Pattern**: جداسازی کامل لایه دسترسی به داده‌ها (`MemoryRepository`, `IMemoryRepository`) از لایه UI.
- **Database**: استفاده از `IndexedDB` به کمک `Dexie` برای ماندگاری و سرعت بالا.
- **Dedicated Services**:
  - `StorageService`: محاسبه حجم مصرفی بر حسب متن، تصاویر، صوت و فایل‌ها.
  - `MediaCompressionService`: فشرده‌سازی عکس‌ها و تولید Thumbnail در بستر Canvas.
  - `EncryptionService`: پیاده‌سازی استاندارد Web Crypto API.
  - `BackupService`: ساخت، اعتبارسنجی و بازیابی بسته‌های رمزگذاری‌شده.
  - `SpeechRecognitionService`: مدیریت تشخیص گفتار سیستمی و مدل‌های محلی Whisper.
  - `PdfExportService`: ساخت PDF سمت کلاینت با jsPDF و html2canvas.
  - `BiometricService`: تعامل با سنسورهای بیومتریک از طریق WebAuthn.
  - `NotificationService`: مدیریت اعلان‌های زمان‌بندی‌شده.

## 🚀 نحوه اجرا و بیلد

```bash
# نصب پکیج‌ها
pnpm install

# اجرای سرور توسعه محلی
pnpm dev

# بیلد نسخه نهایی تولید (Production Build با Service Worker)
pnpm build

# پیش‌نمایش بیلد نهایی
pnpm preview
```

## ⌨️ میانبرهای کیبورد در دسکتاپ

| میانبر | عملکرد |
| :--- | :--- |
| `Ctrl + N` / `Cmd + N` | باز کردن فرم ثبت خاطره جدید |
| `Ctrl + S` / `Cmd + S` | ذخیره سریع خاطره در حال نگارش |
| `Ctrl + F` / `Cmd + F` | انتقال به صفحه جست‌وجو |
| `Escape` | انصراف یا بازگشت به صفحه قبلی |
